# 0008 — Toolchain from nixpkgs; opt-in inference shell; user service

**Status:** Accepted (2026-10-15)

## Decision

- `flake.nix` takes rustc/cargo/clippy/rustfmt straight from nixpkgs (no
  rust-overlay): one input fewer, and the nixpkgs stable compiler suffices.
  `nixpkgs` is locked to the revision other local projects already use, so the
  toolchain comes from the store instead of a download.
- `nix develop` (default): Rust tools, cargo-deny, yt-dlp, ffmpeg-headless,
  sqlite. `nix develop .#inference`: adds whisper.cpp and llama.cpp built with
  `vulkanSupport = true`, plus vulkan-tools. Both were available from the
  binary cache at the locked revision.
- Both shells unset `LD_LIBRARY_PATH`: the host profile exports one built
  against a newer glibc, which makes nixpkgs ffmpeg fail to start.
- `nix flake check` builds the package, which runs the test suite in the
  sandbox (no network, no GPU), catching tests that depend on the host.
- Deployment is a **systemd user service** (Home Manager module plus a plain
  unit for other distributions): no privileges needed, lifecycle tied to the
  user session, Nice 10 and CPU/IO weight 20 so it yields to the desktop, and
  one `MemoryMax` for the whole cgroup including inference children.
- Nothing in the user's global NixOS or Home Manager configuration is changed
  by this repository; enabling the module is the user's decision.
